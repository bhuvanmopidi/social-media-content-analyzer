# Social Media Content Analyzer

Upload PDFs or images, extract text (PDF parsing + OCR), and get
engagement improvement suggestions.

**Live:** _pending_

## Stack
Next.js 15 (App Router) · TypeScript · Tailwind · pdfjs-dist · tesseract.js

## Local setup
\`\`\`bash
npm install
npm run dev
\`\`\`

## Environment
\`\`\`
GROQ_API_KEY=   # optional — app falls back to rule-based analysis without it
\`\`\`
